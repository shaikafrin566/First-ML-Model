# First ML Model with Scikit-learn

## Project Overview
This project demonstrates a machine learning classification task using the Iris dataset from Scikit-learn.

## Dataset
- Iris Dataset

## Algorithms Used
- Logistic Regression
- Random Forest Classifier

## Evaluation Metrics
- Accuracy Score
- Classification Report
- Confusion Matrix

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Results
Both models were trained and compared using the Iris dataset. Their performance was evaluated using accuracy and confusion matrices.
